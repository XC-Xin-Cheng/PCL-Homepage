# PCL 自定义主页安装器（支持 PCL2 / PCL CE）

![PCL 自定义主页](src/icon.png)

为 PCL2 和 PCL CE 一键安装同一套自定义主页。安装器使用图形界面，支持 15 种语言；安装器界面语言会同步决定主页语言。

## 兼容性

仅支持 PCL2 / PCL CE **低于 2.99.0.0 的版本**；2.99.0.0 起不适配。检测到 2.99.0.0 或更高的版本时，安装器会弹窗提示：

> 你这个版本的PCL安装主页已经没有意义了  
> 未对您的计算机进行更改

此时不会写入任何文件、配置或开机自启项，本次安装尝试会直接撤销。已安装旧主页的用户仍可手动卸载，卸载后启动器会恢复自带主页。

## 下载

最新版本见 [GitHub Releases](https://github.com/XC-Xin-Cheng/PCL-Homepage/releases/latest)。发布页提供图形界面 EXE、使用说明和一键安装 ZIP。

## 功能

- 图形界面 EXE，启动时不显示控制台窗口；开机自启、主页按钮、日志刷新和彩蛋也都不显示。
- 无窗口启动由 `PCLHomeLaunch.vbs` 完成（由 `wscript.exe` 启动），安装后请勿删除。
- 命令行参数仍可用于安装和卸载；只有这种命令行模式会显示输出窗口。
- 可选择 PCL2 或 PCL CE，只修改所选启动器的配置，不影响另一个启动器。
- 选择数据文件夹或点击“检测”时只检查路径；点击“安装”后才自动识别并自动选中 PCL2 / PCL CE（两种都支持），不会提前跳转。
- 安装或卸载时若所选启动器仍在运行，会显示“要不要帮你关闭”（不附加括号说明）：YES 只关闭当前选择的启动器，NO 取消且不修改任何内容。
- 15 种语言：简体中文、English、繁體中文、日本語、한국어、Français、Deutsch、Español、Português (Brasil)、Русский、Italiano、Nederlands、Polski、Türkçe、Tiếng Việt。
- 卸载后启动器恢复自带主页，其他界面设置保持不变。
- 兼容包含空格、`&`、括号等字符的路径。
- 不注入 DLL；旧版 `InjectDll.ps1` 已移除，不参与构建。
- 安装后保留主页背景、日志查看器和辅助工具。
- 主页右侧一列三等分为“日志文件夹”“联机”“自定义指令”。
- 主页右侧下方提供“自定义指令”管理器：可新增、编辑、删除、保存并执行 Minecraft 指令。第一次执行时请在 15 秒内点击一次游戏窗口，管理器会静默等待、识别并记住它；之后连续点击两次“执行”确认才会发送。每次点击“选择窗口”都会先清除旧目标，再重新识别你随后点击的窗口并更新目标，不会固定为第一次识别结果。管理器会先确认当前在游戏内，并检查是否有 GUI：有 GUI 会自动关闭并多次确认，确认失败则不执行。识别成功时目标窗口行会短暂显示“识别成功”，3 秒后消失。重新打开管理器后需要重新识别，不保存识别缓存。
- 自定义指令保存在 `PCL\CustomCommands.json`；卸载主页时保留该文件，不绕过服务器权限。
- 主页右侧中间提供“联机”入口，打开陶瓦联机（Terracotta）独立窗口：自动在 `PCL\Online`、HMCL 依赖目录和常见安装位置查找陶瓦联机，未安装时可从官方 GitHub Release 下载（约 8 MB，Gitee 镜像备用）并解压到 `PCL\Online` 后启动。窗口直接内嵌 Terracotta 的控制页面（WebView2），图标使用陶瓦联机本身的图标，可用“关闭联机”优雅停止并清理进程，也可“打开所在文件夹”。陶瓦联机由 burningtnt 开发、AGPL-3.0 许可，本项目只调用官方原版程序，不修改也不捆绑；它用房间码联机，进游戏后在“多人游戏”双击“陶瓦联机大厅”加入，房主需先“对局域网开放”。
- 主页“打开游戏目录”按钮名称不变；悬停提示和实际打开位置已改为当前实例文件夹（无选中实例时回退到游戏目录）。
- 主页中部日志区分成等宽两栏：左边显示当前运行中的游戏日志（latest.log），右边显示上一次游戏启动的日志（游戏 logs 目录里最新的 YYYY-MM-DD-N.log.gz；点“记事本”时先解压到临时文件）。下方“启动器日志”面板保持不变。
- 后台守护脚本每 2 秒重建日志快照并刷新主页；启动器切到最前（成为前台窗口）时再补刷新一次。切到下载、设置等页面时不打扰，回到启动页后自动补刷新。

## 使用

1. 构建或获取 `dist/PCL主页安装[支持CE].zip`。
2. 解压后运行 `PCL主页安装[支持CE].exe`。
3. 选择安装器语言和数据文件夹，然后点击安装；安装器会自动识别并选中对应的 PCL2 / PCL CE。
4. 启动 PCL2 / PCL CE 查看自定义主页。

安装器只写入所选启动器的配置和 PCL 自定义主页目录。卸载时会先要求关闭对应的启动器。

## 构建

环境：Windows 10/11、PowerShell 5.1、.NET Framework 4.x（系统自带 `csc.exe`）。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

输出位于 `dist/`：

- `PCL主页安装[支持CE].bat`：构建中间产物
- `PCL主页安装[支持CE].exe`：图形界面安装器
- `PCL主页安装[支持CE]-使用说明.txt`
- `PCL主页安装[支持CE].zip`：一键安装包，只包含 EXE 和使用说明

## 目录结构

```text
build.ps1               生成 BAT、把 BAT 嵌入 EXE，并打包一键安装 ZIP
src/installer.ps1       安装/卸载逻辑、15 种界面语言和主页语言
src/page.xaml           自定义主页模板，含 @@PCLHOME_*@@ 本地化标记
src/launcher.cs         WinForms EXE 引导器，负责解压并运行内嵌 BAT
src/header.bat          BAT 解压和控制台处理
src/tools/              主页按钮使用的辅助脚本、无窗口启动器和共享背景图
src/tools/PCLHomeLaunch.vbs  无窗口启动器：开机自启、按钮、日志刷新和彩蛋
src/tools/CommandManager.ps1 自定义指令管理器，数据保存在 PCL\CustomCommands.json
src/tools/Online.ps1    联机窗口：查找、下载并启动陶瓦联机（Terracotta）
publish.ps1             维护脚本：通过 GitHub CLI 发布当前源码快照
```

## 说明

- `Custom.xaml` 是 XAML 片段，不是完整 XML 文档。
- 主页可见文本通过 `@@PCLHOME_*@@` 标记本地化，安装时由 `installer.ps1` 替换；辅助脚本内部和页面注释保持中文。
- `src/tools/InjectDll.ps1` 是旧版 DLL 注入脚本，已从当前版本移除，不参与构建。
- 安装器只修改所选启动器（PCL2 或 PCL CE）的配置。
- 一键安装 ZIP 只包含 EXE 和使用说明，BAT 是构建中间产物。
- 旧版安装后重新安装一次，即可把开机自启项从 PowerShell 命令更新为无窗口 VBS。
